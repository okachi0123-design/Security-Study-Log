# CSRFとは
- CSRF(クロスサイトリクエストフォージェリ)：ユーザーがセッションを維持した状態を悪用し、外部の悪意のあるサイトからブラウザを介してリクエストを送り込み、Webサイトに本人からのリクエストだと思わせて不正に操作する攻撃
## 例 
```
パスワード変更をURLのパラメーターから受け取っているログイン機能があるクイズアプリ(quiz@example.com)がある。
`GET /password?change_password=○○`みたいに
↓
ユーザーがこのサイトのセッションを維持した状態で別のサイトにアクセスする。
そのサイト内に細工したクイズアプリのURLを忍ばせる
`quiz.example.com/password?change_password=○○`
↓
利用者がこれをクリックしてアプリに飛んだ時、Web側はログイン済ユーザーが行った操作と勘違いしてパスワードを変更する
```
## 対策
- POSTメソッドのヘッダーや本文に合言葉のパラメータを乗せて重要な変更操作などを行う（GETではそのパラメータがURLに乗ってからRefererなどから見えてしまう）
- 重要な処理の直前で再度パスワード認証を行う
- Refererからリンク元を確認することで、正しいアクセスか確認する
